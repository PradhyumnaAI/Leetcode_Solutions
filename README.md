A structured collection of Data Structures and Algorithms (DSA) problem solutions solved on [LeetCode](https://leetcode.com/). 

All solutions are automatically synchronized in real-time from LeetCode using the **LeetSync** extension.

---

## 📌 Repository Overview

This repository serves as a record of my problem-solving journey across core computer science concepts, including:
- **Arrays & Hashing**
- **Two Pointers & Sliding Window**
- **Stack & Queues**
- **Linked Lists**
- **Trees, Tries & Graphs**
- **Dynamic Programming & Greedy Algorithms**

Each problem directory contains:
1. `README.md` – Complete problem description, difficulty rating, and runtime/memory performance benchmarks.
2. Source Code – Optimized implementation file(s) formatted by language.

---

## 🚀 Key Features

- **Automated Commit Tracking:** Problem descriptions, execution metrics, and code submissions are pushed immediately upon receiving an **Accepted** verdict on LeetCode.
- **Performance Optimized:** Focus on writing clean code with optimal time and space complexities.
